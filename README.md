## Quick Start

The complete prototype web application is located inside the [`app`](file:///c:/USM/XSense/app) directory.

```bash
# 1. Enter the app directory
cd app

# 2. Install dependencies
npm install

# 3. Launch the development server
npm run dev -- --host 127.0.0.1 --port 5173
```

Then visit:
```text
http://127.0.0.1:5173/
```

For full architecture details, judge walkthrough script, and mobile/desktop compatibility documentation, see [`app/README.md`](file:///c:/USM/XSense/app/README.md).
